# MediaProc GUI

## Run locally
```bash
pip install -r requirements.txt
python server.py
# Open http://localhost:5000
```
FFmpeg required for video/audio: `brew install ffmpeg` / `sudo apt install ffmpeg`

## Deploy to Render.com (FREE — recommended)
1. Push this folder to a GitHub repo
2. Go to render.com → New → Web Service
3. Connect your repo → Deploy
4. Live at: https://your-app.onrender.com

## Deploy to Railway (FREE)
1. Push to GitHub
2. railway.app → New Project → Deploy from GitHub
3. Select repo → auto-deploys
4. Live at: https://your-app.up.railway.app
